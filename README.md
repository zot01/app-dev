# Stranger Things

*Stranger Things* is a **sci-fi horror** series created by the Duffer Brothers.  
It first premiered on **Netflix** in *2016* and has become one of the platform’s most popular shows.

## 🧒 Main Characters

1. Eleven  
2. Mike Wheeler  
3. Dustin Henderson  
4. Lucas Sinclair  
5. Will Byers
